# Brainstorming game names

Start from the one-line brief: the genre words a shopper types and the fantasy in plain words.
Write 8 to 15 names across the patterns below, then cut to 3 to 6.

## Patterns

| Pattern | What it does | Example shape (made up) | Watch for |
|---|---|---|---|
| Fantasy verb + object | Says what the player does | "Haunt the Inn" | Common words, weak for search |
| Place or thing from the world | Feels like a world, invites curiosity | "Lantern Tide" | Needs the capsule to say the genre |
| Invented compound | Unique, easy to own and protect | "Brambleborne" | Must be spelled the way it sounds |
| Name + genre subtitle | Unique core, genre in the subtitle | "Thornwick: A Farming Roguelike" | Core alone must still work as a handle |
| Pun on a genre word | Memorable, says the genre | a play on "harvest" or "dungeon" | Puns that need to be read, not heard |
| Character name | Personal, good for a mascot | "Pip and the Pumpkins" | Weak if the character is not on the capsule |

## Filters for the cut

- **Hear it, type it:** one listening, one correct spelling. No digits for letters, no
  apostrophes inside words, no silent letters in invented words.
- **Says the genre or the fantasy**, alone or with the capsule. A name that sounds like the wrong
  genre (a cozy game with a grim name) costs clicks.
- **Search:** at least one word that is not a common English word or a generic game word
  (legend, quest, saga, simulator, survival, kingdom).
- **Handle and hashtag:** the core name without spaces fits 15 characters for X and 18 for a
  .bsky.social handle. Read it as one lowercase word and check it does not spell something else.
- **Not leaning on a famous game:** avoid using a big title's distinctive word.
- **Works in the markets you sell in:** ask the user to check that no word means something rude
  or silly in the main languages of their players.

## Questions to ask the user

1. Which name do you already like, and what do you like about it?
2. Do you plan a mobile or console version? (30 characters on mobile stores.)
3. Is the store page already through Valve's review?
4. Is there a word players use for your game already (in your Discord, in comments)?
